M-VAVE

Official Open

#

Latest V12 Updated 14 Oct 2026 151151 stars on GitHub

M-VAVE's own open-source firmware, which turns the FM1 into an eight-track groovebox: each track plays a DX7, 303, 808, PSG, Pluck, or sampler engine, with 16 USER project slots and an eight-slot sample bank every project shares. It installs from M-VAVE's FM1 Workbench, which also edits projects, simulates the device, and can put V15 back. This editor recognises it and sends it no Program Change or effect controls, which would change its tracks, but sends it no patches yet: a DX7 track takes a voice or bank downloaded from this editor as a .syx file, through the Workbench.

Going back: the Workbench's Restore original V15 replaces all four banks with the factory voices, and a force flash may erase projects and samples, so download a backup from this editor first.

M-VAVE

Stock firmware

#

Works with this editor Latest V15 Updated 30 Jul 2026 Not on GitHub

The firmware every FM1 ships with: a six-operator FM engine compatible with DX7 voices, four banks of 32 presets, effects, an arpeggiator, and a sequencer. Install it with M-VAVE's M-UPGRADE tool, which is also the way back from Felucca and SLOOP.

Going back: download V15 from M-VAVE's downloads, under PC Firmware, and install it over whichever firmware the FM1 runs; many custom firmwares' own installers can put it back too. If SLOOP, or a firmware built on it such as sloopDX or zp12, no longer starts, hold OCT− alone while switching the FM1 on: it starts in USB rescue, ready to install again.

M-VAVE also publishes a groovebox firmware of its own, Official Open, listed above.

FM-1 Macropad Patch

#

Works with this editorPatches V15 · Latest 1.0.0 Updated 12 Oct 2026 22 stars on GitHub

A patcher, not a firmware, which changes your own copy of M-VAVE’s V15 so that every button, key, and knob sends a USB-MIDI note, fourteen buttons, 27 keys, and seven knobs each way, which an app such as Keyboard Maestro or MidiKey2Key turns into shortcuts. The synth functions go, and so does the settings screen, so set the velocity you want with M-VAVE’s firmware before patching.

The patched file may not be shared, so you download V15 yourself and patch it in the web page or with Python, then install it with M-UPGRADE. Its README says no recovery method is known if an update fails; M-VAVE’s updater puts V15 back.

Watch list

#

Firmwares on their way that cannot be installed on an FM1 yet. Each joins the list above once it can.

  • AMBII ↗ MilkBoyG

    An ambient firmware built on Melodee, for slow, expressive sound design and performance. So far it is a browser prototype, with no FM1 build released.

  • Haave ↗ thebrodi

    A simple, dreamy ambient firmware for live meditation, a Felucca fork, formerly called Drift. So far it has run only in a browser emulator, and has not been flashed to an FM1.

  • DriftSeq ↗ johnskiller

    A 16-track polymetric sequencer. Its web emulator is live, but there is no firmware build yet.

  • fm1-doom ↗ Keitark

    Doom's engine on the FM1, by FM-1 NES's author. Its firmware and the loading of game data are still being written, and no build is offered for installing.

  • FM1 MDX karaoke player ↗ Keitark

    Plays MDX and PDX songs on a software YM2151 and lets you mute a part and play it on the keys. It has been tested on a computer but not yet installed on an FM1.

  • FM1 Move ↗ Nicodesy06

    An eight-track groovebox built from SLOOP. Its device page can install it, and community testers have run earlier builds on FM1s, but there has been no structured hardware test.

  • fm1-polyseq ↗ NOVALENTI

    A polyphonic 16-step sequencer and hardware layer written from scratch in C. It is published as source only.

  • fm1-radio ↗ Charles Vestal

    An internet radio over WiFi: it plays stations from Radio Garden's map, with punch-in effects on the keys. Its first release, 1.0, is withdrawn: its notes say it crashes on some FM1s when WiFi starts, and a fixed release will follow.

  • fm1-zed ↗ cmlarsen

    A custom firmware based on Felucca. It has no release of its own yet.

  • FM80S ↗ y6zkcqnf5r-hue

    A synth-looper: play a loop on the keys, then another instrument over it, or program one step by step. It is being written in a browser first, and its notes are in French.

  • FRASIL ↗ styvesgoupil

    An ambient drone and texture firmware: you latch drones and chords, with no sequencer, into a large reverb with shimmer and freeze. Its notes call it beta, but there is no release or installer page yet.

  • Lunar Modulator ↗ ip2k

    Open firmware with engines derived from Mutable Instruments' modules and a Movy-style sequencer. It runs only as a virtual FM1 in a browser, and has never written anything to an FM1.

  • MD-One ↗ d0pe1

    A drone machine built from Mutable Instruments' engines. Its README says it has run only on a computer and in an emulator, and that no FM1 had been connected.

  • MONO2K ↗ InigoHernandez

    A Monomachine-style firmware of six tracks, with a 64-step sequencer. Its README calls it a prototype that runs in a browser, with no FM1 build yet.

  • more chords ↗ rosen-wav

    A ChoralRoot remix with engines adapted from Melodee and ORBIT. It has a web installer page and an emulator, but no release and no licence stated.

  • NoteSorcery ↗ catacombius

    An eight-track firmware that works with Ableton and an Android app. It has its own installer page, but has been tested only on a computer, not yet on an FM1.

  • Oktowave ↗ PierreArnaudGUYOT

    Felucca 1.6.1 with a WAVELET engine from the Wavelet Synthesizer, and 108 of its presets. Its README says version 0.1 has not been run on an FM1 yet.

  • Optimist ↗ w0ts

    A modular platform built from SLOOP: you choose the engines, kits, and effects, and build a firmware that holds them. It now runs on its developer's FM1, but there is no installer or ready-made build: you build it yourself.

  • Patricktronics ↗ gaumondp

    A generative layer on Felucca. It has install instructions but no release, and has not been confirmed on an FM1.

  • REGGAE-OS ↗ KemstheSage

    A reggae synth firmware based on Felucca. Its notes call it an early development build whose hardware is untested.

  • Rocket OS ↗ cmlarsen

    A clip-launching performance firmware forked from X0X. It has no build of its own yet.

  • SIDOU ↗ dsablic

    A C64 SID tracker-synth. Its 0.2.0 preview release is marked as untested on hardware, and it has been tried only in an emulator.

  • SLICE64-FM ↗ jeymadcat-ops

    A four-track tracker with SID, FM, and sampler engines. Its web editor is public, but the firmware is not yet.

  • UNIBOX ↗ chinotto1

    A nine-track groovebox built on FOMAJAM, with an arranger, free recording, and a USB sampler. It is published as source only.

  • Vector37 ↗ genkigenki

    An orbiting overtone synth written for the SMK-37 keyboard. Its page lists a 0.3 beta build for the FM1 and says it has not been tried on one.

Pictures come from each project's own pages. Know of a firmware missing here? Open an issue.
