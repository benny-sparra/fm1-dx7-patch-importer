M-VAVE

Official Open

#

Latest V14 Updated 19 Oct 2026 246246 stars on GitHub

M-VAVE's own open-source firmware, which turns the FM1 into an eight-track groovebox: each track plays a DX7, 303, 808, PSG, Pluck, or sampler engine, with 16 USER project slots and an eight-slot sample bank every project shares. It installs from M-VAVE's FM1 Workbench, which also edits projects, simulates the device, and can put V15 back. This editor recognises it and sends it no Program Change or effect controls, which would change its tracks, but sends it no patches yet: a DX7 track takes a voice or bank downloaded from this editor as a .syx file, through the Workbench.

V14 holds 128 independent DX7 voices in four groups of 32 and takes DX7 single-voice and 32-voice bank SysEx.

Going back: the Workbench's Restore original V15 replaces all four banks with the factory voices, and a force flash may erase projects and samples, so download a backup from this editor first.

M-VAVE

Stock firmware

#

Works with this editor Latest V16 Updated 21 Oct 2026 Not on GitHub

The firmware every FM1 ships with: a six-operator FM engine compatible with DX7 voices, four banks of 32 presets, effects, an arpeggiator, and a sequencer. Install it with M-VAVE's M-UPGRADE tool, which is also the way back from Felucca and SLOOP. V16, released on 21 October, makes the FM1 eight-part multitimbral, with 20 voices shared between the parts, longer patterns, and one library of 128 effect settings that every preset shares; this editor has not been tested with it yet.

Going back: download the stock firmware from M-VAVE's downloads, under PC Firmware, and install it over whichever firmware the FM1 runs; many custom firmwares' own installers can put it back too. If SLOOP, or a firmware built on it such as sloopDX or zp12, no longer starts, hold OCT− alone while switching the FM1 on: it starts in USB rescue, ready to install again.

M-VAVE also publishes a groovebox firmware of its own, Official Open, listed above.
