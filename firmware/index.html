M-VAVE

Stock firmware

#

Works with this editor Latest V15 Not on GitHub

The firmware every FM1 ships with: a six-operator FM engine compatible with DX7 voices, four banks of 32 presets, effects, an arpeggiator, and a sequencer. Install it with M-VAVE's M-UPGRADE tool, which is also the way back from Felucca and SLOOP.

Going back: download V15 from M-VAVE's downloads, under PC Firmware, and install it over whichever firmware the FM1 runs; many custom firmwares' own installers can put it back too. If SLOOP, or a firmware built on it such as sloopDX or zp12, no longer starts, hold OCT− alone while switching the FM1 on: it starts in USB rescue, ready to install again.

Baud Girl

Baud Girl (FM-1+VA)

#

Works with this editor Latest FM-1_096 Not on GitHub

Keeps M-VAVE's FM engine and effects, fixes its engine bugs, and adds a Virtual Analog engine, an 8-Bit engine, a Bitcrush effect, and a 64-step sequencer. It installs from Baud Girl's own browser page, keeps your presets, and can put M-VAVE's firmware back. This editor reads and writes its FM and Virtual Analog presets, effects included, but not its 8-Bit presets yet, which it leaves as they are on the FM1.

FM-1 firmware patcher

#

Works with this editorPatches V15 55 stars on GitHub

A script that changes your own copy of M-VAVE's V15 rather than a firmware of its own: operator detune matches Dexed, aftertouch no longer brings a strong vibrato, and the main screen's scope turns dark blue. The FM1 still reports V15, so this editor treats it as M-VAVE's firmware.

The patched file may not be shared, so you run the Python script yourself. M-UPGRADE sees it as the V15 already installed, so go down to V14 with M-VAVE's tone updater first, then install it; the same steps put V15 back.

Watch list

#

Firmwares on their way that cannot be installed on an FM1 yet. Each joins the list above once it can.

  • AMBII ↗ MilkBoyG

    An ambient firmware built on Melodee, for slow, expressive sound design and performance. So far it is documentation only.

  • April OS ↗ beashoko

    A Felucca fork for sampling. So far it has a work-in-progress page and no firmware.

  • FM-1 B-Boy Edition ↗ friendsmakenoise-prog

    A late-90s chop sampler with three sample tracks and an FM lane. Its test builds have run on an FM1, but each is built from your own copy of M-VAVE's firmware, and there is no package or installer to download.

  • fm1-doom ↗ Keitark

    Doom's engine on the FM1, by FM-1 NES's author. Its firmware and the loading of game data are still being written, and no build is offered for installing.

  • FM1 MDX karaoke player ↗ Keitark

    Plays MDX and PDX songs on a software YM2151 and lets you mute a part and play it on the keys. It has been tested on a computer but not yet installed on an FM1.

  • fm1-polyseq ↗ NOVALENTI

    A polyphonic 16-step sequencer and hardware layer written from scratch in C. It is published as source only.

  • Lunar Modulator ↗ ip2k

    Open firmware with engines derived from Mutable Instruments' modules and a Movy-style sequencer. It runs only as a virtual FM1 in a browser, and has never written anything to an FM1.

  • Optimist ↗ w0ts

    A modular platform built from SLOOP: you choose the engines, kits, and effects, and build a firmware that holds them. It has run only in an emulator, never on an FM1.

  • PurpleMonkey FM-1 ↗ Quixotic7

    A firmware for a small child, by ChoralRoot's author: any key plays FM notes on a pentatonic scale over a beat, with four animal friends on the screen. It has run only in an emulator, never on an FM1.

  • SLICE64-FM ↗ jeymadcat-ops

    A four-track tracker with SID, FM, and sampler engines. Its web editor is public, but the firmware is not yet.

Pictures come from each project's own pages. Know of a firmware missing here? Open an issue.
