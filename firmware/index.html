M-VAVE

Stock firmware

#

Works with this editor Latest V15

The firmware every FM1 ships with: a six-operator FM engine compatible with DX7 voices, four banks of 32 presets, effects, an arpeggiator, and a sequencer. Install it with M-VAVE's M-UPGRADE tool, which is also the way back from Felucca and SLOOP.

Baud Girl

Baud Girl (FM-1+VA)

#

Works with this editor Latest FM-1_096

Keeps M-VAVE's FM engine and effects, fixes its engine bugs, and adds a Virtual Analog engine, an 8-Bit engine, a Bitcrush effect, and a 64-step sequencer. It installs from Baud Girl's own browser page, keeps your presets, and can put M-VAVE's firmware back. This editor reads and writes its FM and Virtual Analog presets, effects included, but not its 8-Bit presets yet, which it leaves as they are on the FM1.

A chord instrument inspired by Telepathic Instruments' Orchid: one hand plays roots while the other shapes chords, with voicings, key and performance modes, a bass line, and a looper. Felucca

#

Not supported by this editorLatest 1.0.5.1

Turns the FM1 into a multi-engine synth: thirteen engines, from analogue, six-operator FM, and phase distortion to samples, granular, drums, and physical models from Mutable Instruments' Plaits and Rings, across four tracks with a 64-step sequencer, arpeggiator, and modulation matrix. It has its own web editor and installer, and a browser emulator to try first.

hericdk

FM1 Quest

#

Not supported by this editorNot yet tried on an FM1

SLOOP as a pixel-art RPG. The four tracks are four heroes, every lit step is an attack, the tempo sets how fast the party walks, the key picks the biome, effects bring the weather, and recording a loop is a boss fight against the King Slime. Every SLOOP function stays where it was, with the same controls. It installs from its own browser page, and SLOOP's own release installs over it.
