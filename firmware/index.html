The FM1 can run more than the firmware it ships with. These are the firmwares known to run on it, each from its own maker. This site installs none of them: every link goes to the project's own pages and installer. Back up your patches before you switch.

M-VAVE

Stock firmware

Works with this editor Latest V15

The firmware every FM1 ships with: a six-operator FM engine compatible with DX7 voices, four banks of 32 presets, effects, an arpeggiator, and a sequencer. Install it with M-VAVE's M-UPGRADE tool, which is also the way back from Felucca and SLOOP.

Madeline Hoyle (Baud Girl)

Baud Girl (FM-1+VA)

Works with this editor Latest FM-1_096

Keeps M-VAVE's FM engine and effects, fixes its engine bugs, and adds a Virtual Analog engine, an 8-Bit engine, a Bitcrush effect, and a 64-step sequencer. It installs from Baud Girl's own browser page, keeps your presets, and can put M-VAVE's firmware back. This editor reads and writes its presets, effects included.

Hügelton Instruments

Felucca

Not supported by this editor Beta · Latest 0.9

Turns the FM1 into a multi-engine groovebox: nine engines, from analogue, FM, and phase distortion to samples, formant voice, organ, and granular, across three synth parts and a drum track, each with its own 64-step sequencer. It has its own web editor and installer. It ignores DX7 voice data, so patches from this editor do not reach it.

isod89

SLOOP

Not supported by this editor Beta · Latest 2.2

A groovebox firmware built on Felucca, with projects, patterns, and songs, and its own web editor for presets and a sound library. It installs from its own browser page and leaves through M-VAVE's M-UPGRADE, as Felucca does.
