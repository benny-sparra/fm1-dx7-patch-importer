# M-VAVE SMK-37 Pro: second hardware run, 2026-11-08

Parts A and B of [`smk37-second-run-sheet.md`](smk37-second-run-sheet.md) on Ben's SMK-37 Pro,
still on stock V015, over USB-C to a Mac. Every message was sent once from `smk37-send.swift` to
`SMK-37 Pro-Private`; the tool listened on all three SMK sources for 1.5 s after each send, and
for 3 s more after each dump request. A0, the static check, was skipped: the requests themselves
answer the question. Parts C1 and C2 were not run.

## Summary

- **No readback.** Neither the DX7 single-voice dump request nor the bank dump request got any
  reply. The stock V015 app sends nothing over MIDI but the identity reply, as in the first run.
- **No way to choose the preset.** Bank Select (0 or 1, LSB 0) before Program Change on channel
  1, and Program Change on channel 10 (the Pad channel) and 16, all left the preset on screen
  unchanged.
- **Two screens, two presets.** GLOBE's **Preset-1** and the home screen's **Preset-1** are the
  controller preset (Scale, Chord, Pad Bank, Arpeggiator, Note Repeat, Keys and Pads channels).
  The sound is on the synth screen: a number and name (`8 O-F-SEQ 1`), the four banks **BANK A**
  to **BANK D** with the selected one lit, **Latch**, and **SAVE** on K8.

- GLOBE: Preset-1, Key Chn 1, Pad Chn 10, Key Vel 2, Pad Vel 2, Pad Aft On, Pedal SUS.

## What the results decide

- The SMK-37 on stock V015 stays send-only: the `smk37` profile gains no readback, and the
  receive wizard cannot ask it for a patch. Reading a patch back needs SMK37 OPEN (part C2), whose
  approved Official Open reads cover a track's voice and a bank.
- The editor cannot choose which preset a dump replaces. A **Write to SMK-37…** action would ask
  the user to select the preset on the synth screen first, then send one single-voice dump, which
  the first run confirmed replaces the selected preset and survives a power cycle.
- Its wording must name the synth screen's bank and number (`BANK A`, `8`), not GLOBE's or the
  home screen's **Preset**, which is the controller preset.
